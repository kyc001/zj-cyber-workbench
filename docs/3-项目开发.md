# 项目开发

## 一、开发环境

项目主要在 Windows 10/11 x64 下开发。基础工具包括：

- Python 3.12
- uv
- Node.js 22+
- pnpm 10
- Git
- PowerShell

环境检查：

```powershell
.\scripts\dev.ps1 doctor
```

依赖安装：

```powershell
.\scripts\dev.ps1 install
```

该命令会执行 Python 依赖同步和 pnpm workspace 依赖安装。

## 二、启动方式

启动后端：

```powershell
.\scripts\dev.ps1 backend
```

启动主工作台前端：

```powershell
.\scripts\dev.ps1 web
```

快速 UI 联调：

```powershell
.\scripts\dev.ps1 ui
```

启动 Skill Hub 后端：

```powershell
python skill_hub_main.py
```

启动 Skill Hub 前端：

```powershell
pnpm dev:skill-hub
```

## 三、主要开发内容

### 1. Agent Runtime

完成 Agent 模型适配、Agent 角色注册、会话池、流式事件、上下文压缩、子代理任务、报告生成、任务中断和恢复。Mock Model 用于测试 Agent Runtime，不依赖真实模型即可验证核心链路。

### 2. 后端接口

实现认证、用户、主机、出口代理、沙箱工作区、项目、知识库、Agent 会话、审批、运行权限、Skill Hub、系统配置和 Toolpack 等 API。接口层采用 `router -> handler -> service` 的分层方式。

### 3. 前端工作台

实现 Playground、Container Shell、文件管理器、Admin 资源页、Toolpack 页面、知识库页面、项目页面、系统配置和 Skill Hub 入口。前端通过 typed client 调用后端接口，并尽量保持操作路径可视化。

### 4. 执行与工具箱

实现本机和 SSH 工作区的命令执行、异步任务、任务取消、SFTP 文件操作、路径安全校验和 Toolpack 结构化运行。Toolpack 支持工具可用性检查、输入校验、策略限制、结构化输出和 artifact。

### 5. Skill Hub

实现独立 Skill Hub 后端和前端，包括注册登录、命名空间、Skill 发布、包校验、列表检索、详情、下载、收藏、评分和审计。工作台侧实现 Skill Hub 页面和 Skill 安装接口。

### 6. 桌面与打包

实现 Electron 主进程、preload、sidecar 管理器、splash 窗口、loopback 端口分配、运行数据目录、桌面登录回调和 Windows 构建脚本。打包流程包括 React 构建、PyInstaller sidecar 构建和 electron-builder 打包。

## 四、数据与配置

开发环境默认使用仓库下 `.zj/` 保存配置、数据库、日志、Skill 和 artifact。桌面打包运行时默认使用用户本地数据目录：

```text
%LOCALAPPDATA%\Zhenjun\Data
```

主要配置项包括：

- 后端监听地址和端口。
- SQLite 数据库位置。
- Agent 模型服务地址、API Key 和模型名。
- LightRAG embedding 和 LLM 配置。
- 权限模式和审批超时。
- Agent Runtime 会话池和上下文压缩参数。

## 五、测试

后端单元测试和集成测试：

```powershell
uv run python -m unittest discover -s tests -p "test_*.py"
```

前端类型检查：

```powershell
pnpm typecheck
```

整体构建：

```powershell
pnpm build
```

D 模块相关测试：

```powershell
pnpm test:d-runtime
pnpm test:d-web
```

测试覆盖了数据库初始化、权限、Toolpack、网络工具、Agent Runtime、Skill Hub 包校验、桌面会话、配置读取和前端 E2E 场景。

## 六、打包

Windows portable 打包：

```powershell
pnpm package:portable
```

Windows 完整构建：

```powershell
pnpm package:windows
```

构建脚本会：

1. 创建独立 build venv。
2. 安装 Python 和 Node 依赖。
3. 构建 React renderer。
4. 用 PyInstaller 构建 Python sidecar。
5. 构建 Electron main process。
6. 用 electron-builder 输出 installer 或 portable。
7. 生成 SHA256SUMS 和 build manifest。

## 七、开发注意事项

- 不提交 `.env`、`.zj/`、数据库、日志、artifact 和打包产物。
- 修改 API schema 后需要重新导出 OpenAPI 并生成前端类型。
- Toolpack 和文件操作必须通过统一服务层，避免绕开路径和权限校验。
- 桌面 sidecar 只允许绑定 loopback 地址。
- Skill Hub 发布流程只校验和存储 Skill 包，不执行包内容。
